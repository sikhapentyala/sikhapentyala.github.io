# Sikha Pentyala — website

Plain HTML, CSS, and a little JavaScript. **No build step, no framework, nothing to install.**

## Testing locally

Double-click `index.html`. That's it — it opens in your browser and works exactly as it will
once uploaded. Edit a file, save, hit reload.

## Where things live

| I want to... | Edit this file |
|---|---|
| Add or change a publication | `publications.js` |
| Add a news item | `news.js` |
| Change the research directions, projects | `research.html` |
| Change courses or mentees | `teaching.html` |
| Change talks, reviewing, awards | `service.html` |
| Change the bio | `index.html` |
| Change nav links or the footer | top of `site.js` |
| Change colours, fonts, spacing | top of `style.css` |

## Adding a publication

Open `publications.js`, copy any existing block, paste it near the top, edit the fields:

```javascript
{
  title: "Your Paper Title",
  authors: "S. Pentyala, A. Student*, M. De Cock",
  venue: "ICML", year: 2027, kind: "conference",
  areas: ["synthetic", "privacy"],
  note: "25% acceptance",
  url: "https://link-to-paper",
  selected: true,
},
```

- Your name gets **bolded** automatically — just write `S. Pentyala`.
- `kind` is one of: `conference`, `journal`, `workshop`, `preprint`, `patent`.
  Each gets its own colour-coded label on the page.
- `areas` is a **list** — use as many as genuinely apply. A paper can be
  Synthetic Data *and* Privacy *and* AI for Good. Keys must match `AREAS`
  at the top of the file. These become the labels on the paper, and the
  filter tabs at the top of the page.
- `selected: true` also puts it on the home page. Delete the line to remove it.
- `note` and `url` are optional — delete the lines if not needed.
- The `*` after a student's name is kept in the data for your own reference
  but is **not** displayed anywhere on the site.

**Watch out for:** every field ends with a comma, and every block ends with `},`. If the page
goes blank, that's almost always a missing comma or quote. Open the browser console
(Cmd+Option+J in Chrome) and it will tell you which line.

## Renaming or reordering the research areas

Edit `AREAS` at the top of `publications.js`:

```javascript
const AREAS = [
  { key: "synthetic", label: "Synthetic Data" },
  { key: "privacy",   label: "Privacy" },
  ...
];
```

Change a `label` and it updates the filter tabs and every paper label at once.
Change the order here and the tabs reorder. Keep labels short — the tabs are
meant to sit on one line.

## Uploading to GitHub

Upload the changed files to the repository root. The whole site is these files:

```
index.html  research.html  publications.html  teaching.html  service.html
style.css  site.js  publications.js  news.js
images/  CV_2026.pdf
```

You can also edit any of them directly on github.com — pencil icon, edit, commit.

## Notes

- The nav and footer are generated by `site.js` so they only exist in one place.
  That's why the HTML files have `<nav id="nav"></nav>` and `<footer id="footer"></footer>`.
- Publications are rendered by JavaScript. Google indexes this fine, but simpler
  scrapers won't see the list.
